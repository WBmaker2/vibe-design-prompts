# 바이브 코딩 30가지 디자인 프롬프트

PDF에서 추출한 실제 이미지 30개와 TXT 원문을 연결하는 반응형 갤러리입니다.

공개 웹페이지: https://wbmaker01-ai.github.io/vibe-design-prompts/

공개 소스 저장소: https://github.com/wbmaker01-ai/vibe-design-prompts

`main` 브랜치에 변경 사항을 푸시하면 검색 테스트와 코드 검증을 실행한 뒤 GitHub Pages로 자동 배포합니다. 정적 배포에는 `dist/` 폴더만 포함됩니다.

## 사용법

`dist/index.html`을 브라우저로 열면 인터넷 연결 없이도 사용할 수 있습니다. 디자인 이미지를 누르면 해당 원문 모달이 열리고, **프롬프트 복사** 버튼으로 전체 내용을 복사할 수 있습니다.

학습/아카데믹, 자연/에코, 레트로/빈티지, 판타지/드림, 모던/도시, 럭셔리/프리미엄 필터를 지원합니다. 제목·원문·분위기·색상 코드를 검색할 수 있으며, 필터와 검색이 동시에 적용됩니다. Escape, 닫기 버튼 또는 배경 클릭으로 모달을 닫습니다.

브라우저가 자동 복사를 허용하지 않으면 선택된 원문을 Ctrl+C 또는 ⌘C로 복사하세요.

## 파일 구성

- `dist/index.html`: 페이지와 모달 구조
- `dist/styles.css`: 반응형 화면과 동작 줄이기 지원
- `dist/app.js`: 이미지 목록, 모달, 복사, 필터 UI
- `dist/gallery-core.js`: 검색과 카테고리 필터
- `dist/data.js`: TXT에서 추출한 30개 원문
- `dist/assets/`: PDF에서 추출한 30개 전체 미리보기 이미지
- `scripts/extract_assets.py`: 원본 재추출 및 PDF/TXT 식별자·제목 대조
- `scripts/core.test.cjs`: 검색·필터 테스트

원문 프롬프트는 제작 지시로 실행하지 않고 자료로만 사용했습니다. 코드펜스를 제거했으며 본문의 문구와 들여쓰기는 보존했습니다.

# 바이브 코딩 30가지 디자인 프롬프트 워크스페이스

PDF에서 추출한 30가지 실제 디자인 스타일 시안(120개 예시)과 TXT 원문 프롬프트를 보존하고, 실전 바이브 코딩을 위한 **리믹스 프롬프트**, **AI 코딩 지시문**, **디자인 토큰(CSS/Tailwind)**을 실시간 생성하는 정적 웹 워크스페이스입니다.

- 공개 웹페이지: https://WBmaker2.github.io/vibe-design-prompts/
- 공개 소스 저장소: https://github.com/WBmaker2/vibe-design-prompts

`main` 브랜치에 변경 사항을 푸시하면 13개 단위 테스트와 브라우저 스크립트 문법 검증을 실행한 뒤 GitHub Pages로 자동 배포됩니다. 빌드 도구 없이 `dist/` 폴더만 정적 배포됩니다.

---

## 주요 기능 및 사용법

`dist/index.html`을 브라우저로 열면 인터넷 연결 없이도 로컬(`file://`)에서 즉시 실행됩니다.

1. **4대 출력 포맷 실시간 변환 및 원클릭 복사**
   - **원문 프롬프트**: 원본 텍스트 및 들여쓰기 100% 무손실 보존
   - **커스텀 리믹스**: 프로젝트 주제(예: "독서 기록 앱")와 타겟 UI 환경을 결합한 맞춤형 프롬프트
   - **AI 코딩 지시문**: Cursor, Claude, Antigravity 등 코딩 에이전트에 바로 입력할 수 있는 구조화된 UI 구현 프롬프트
   - **CSS / Tailwind 토큰**: `:root` CSS 변수와 Tailwind 색상 설정 스니펫 자동 생성
2. **4분할 시안 확대 뷰어 (Split-Cut Viewer)**
   - 4개 세로 시안이 포함된 고해상도 이미지를 **전체 4컷**뿐 아니라 **시안 1~4** 개별 탭으로 전환하여 디테일과 텍스트를 크게 확대해서 확인
3. **대화형 컬러 팔레트 칩**
   - 각 디자인의 배경색, 본문색, 포인트 강조색 칩을 표시하고, 클릭 시 해당 HEX 코드 즉시 복사
4. **실시간 UI 테마 미리보기 (Live Theme Sandbox)**
   - 선택된 디자인의 배경색, 텍스트색, 포인트 컬러가 실제 웹 컴포넌트(배지, 헤딩, 본문, 버튼)에 적용된 모습 실시간 렌더링
5. **카드 원클릭 액션 & 즐겨찾기 보관함**
   - 모달 진입 없이 카드에서 원문 빠른 복사(`⧉`) 및 즐겨찾기(`★`) 토글
   - 상단 카테고리에 **★ 즐겨찾기** 필터 탭 제공 (`localStorage` 영구 보관)
6. **URL 딥링크 공유 & 연속 탐색**
   - 카테고리, 검색어, 선택된 프롬프트가 URL 파라미터(`?category=...&q=...&prompt=...`)와 실시간 동기화
   - 모달 안에서 이전/다음 버튼 또는 키보드 방향키(`←`, `→`)로 연속 탐색 가능
7. **다크 모드 지원**
   - 우측 상단 테마 버튼으로 따뜻한 아이보리 라이트 테마와 잉크 다크 테마 전환

## 파일 구성

- `dist/index.html`: 반응형 웹페이지, 4분할 뷰어, 워크스페이스 모달 구조
- `dist/styles.css`: 디자인 토큰, 다크 모드, 4컷 줌, 컬러칩, UI 프리뷰 및 반응형 미디어쿼리
- `dist/app.js`: 갤러리 렌더링, 4컷 줌 뷰어, 클립보드 복사, 딥링크, 북마크, 테마 컨트롤러
- `dist/gallery-core.js`: 검색·북마크 필터, 프롬프트 구조 파서, 4대 포맷 변환 엔진
- `dist/data.js`: TXT 원문에서 추출한 30개 디자인 스타일 데이터 (30개 항목)
- `dist/assets/`: PDF에서 추출한 30개 고해상도 미리보기 이미지 (`1436×613`)
- `scripts/core.test.cjs`: 13개 단위 테스트 (필터, 즐겨찾기, 구조 파서, 다중 포맷 내보내기)
- `scripts/extract_assets.py`: 원본 PDF/TXT 검증 및 이미지 재추출 스크립트
